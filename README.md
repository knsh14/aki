# Aki（あき）

メニューバーにストレージの空き容量を表示する macOS アプリ。クリックすると大まかな内訳と、ホーム以下の大きいフォルダ／ファイルを階層をたどって確認できる（閲覧専用で、削除機能はない）。

- メニューバー: 空き容量（60 秒ごとに更新。空きが 10% 未満のときは警告アイコン）
- ポップオーバー: 使用率バーと内訳（アプリ／ホーム／システム／その他／空き）、ホームの大きい項目（50MB 以上、各階層の上位 20 件）
  - フォルダをクリックすると中へ、ファイルをクリックすると Finder で表示。右クリックでパスをコピー
- ログイン時に起動: `/Applications` か `~/Applications` から初めて起動したとき、自動でログイン項目に登録する。ポップオーバーのチェックボックスで切り替えられる（`build/` から起動した版は登録しない）
- スキャン結果は `~/Library/Caches/dev.aki.Aki/scan.json` にキャッシュする。起動時、前回のスキャンから 1 時間以上たっていれば再スキャンする

## 実装のしかた

このリポジトリには実装（Swift のソース、テスト、ビルドスクリプト）が入っていない。
入っているのは、Aki を再現するための仕様 [AGENTS.md](AGENTS.md)、この README、[LICENSE](LICENSE) だけである。
各自の手元で、コーディングエージェントに AGENTS.md を読ませて実装させる。

1. リポジトリを手元に置き、そのディレクトリでコーディングエージェント（Claude Code、Codex など）を起動する。
2. 「AGENTS.md の仕様どおりに Aki を実装して、テストとビルドを通して」と頼む。
3. できたら、下の「ビルドと起動」の手順でインストールする。

生成したファイルはコミットしない。
git なら `.git/info/exclude` に追加して、追跡対象から外しておく。
仕様を変えたいときは AGENTS.md を更新してコミットする。

## ビルドと起動

実装した後に使う。
macOS 14 以降と Xcode（Swift 6）が必要。

```bash
make app       # build/Aki.app を作る（ad-hoc 署名）
make run       # ビルドして起動
make install   # ~/Applications にコピー
make test      # ユニットテスト
```

## 権限について

- 初回スキャン時、デスクトップ／書類／ダウンロードや「他のアプリのデータ」へのアクセス許可を求めるダイアログが出る。
- `~/Library/Mail` などはフルディスクアクセスがないと読めず、その分サイズが小さく表示される。ポップオーバーの「フルディスクアクセス…」から設定画面を開き、Aki を許可する。
- ad-hoc 署名のため、**再ビルドするとアプリの識別情報が変わり、許可をやり直す必要がある**。一度 `make install` した後は再ビルドを控えるとよい。

## 数値の意味

- 空き: Finder の「使用可能」と同じ基準（パージ可能な領域を含む）。`df` の値より大きく出ることがある。
- システム: 読み取り専用のシステムボリューム、VM（スワップ）、Preboot の使用量。
- その他: 使用量からアプリ、ホーム、システムを引いた残り（/Library、/private/var、スナップショットなど）。マイナスになる場合は 0 として表示する。
- サイズは実際に割り当てられたブロック数で数える（`du` と同じ）。ハードリンクは 1 回だけ数え、iCloud などで未ダウンロードのフォルダには入らない。

## 開発用

```bash
build/Aki.app/Contents/MacOS/Aki --scan ~/some/dir   # UI を出さずに集計結果を出力
build/Aki.app/Contents/MacOS/Aki --snapshot out.png Library   # キャッシュからポップオーバーを PNG に（~/Library を掘った状態）
```
